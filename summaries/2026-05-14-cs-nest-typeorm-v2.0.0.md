# @cs/nest-typeorm v2.0.0 摘要

## 一句话

@cs/nest-typeorm 是 MWP Packages Project 的 ORM 封装包，基于 TypeORM，支持多数据库连接和动态实体加载。

## TL;DR

- **多数据库连接**：支持多个命名数据库实例
- **动态实体加载**：自动扫描并注册实体
- **TypeORM 封装**：forRoot / forRootAsync 动态模块
- **事务管理**：装饰器和手动事务控制
