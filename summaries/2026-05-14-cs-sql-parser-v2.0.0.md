# @cs/sql-parser v2.0.0 摘要

## 一句话

@cs/sql-parser 是 MWP Packages Project 的 SQL 解析包，提供 SQL 语法解析、分析和转换能力。

## TL;DR

- **SQL 解析**：解析 SQL 语句为 AST
- **语法分析**：提取表名、字段、条件等
- **SQL 转换**：支持 SQL 格式化和重写
