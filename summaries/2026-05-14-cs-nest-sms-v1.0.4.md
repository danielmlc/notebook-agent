# @cs/nest-sms v1.0.4 摘要

## 一句话

@cs/nest-sms 是 MWP Packages Project 的短信工具包，支持多短信服务商适配（阿里云/腾讯云）。

## TL;DR

- **多云适配**：阿里云短信 / 腾讯云短信
- **SmsService**：统一短信发送接口
- **SmsModule**：forRoot / forRootAsync 动态模块配置
