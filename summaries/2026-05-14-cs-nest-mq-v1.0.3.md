# @cs/nest-mq v1.0.3 摘要

## 一句话

@cs/nest-mq 是 MWP Packages Project 的消息队列包，支持开源 RocketMQ 5.x 和腾讯云 RocketMQ，提供装饰器驱动的消费者/生产者注册。

## TL;DR

- **装饰器驱动**：@Handler / @Producer 标注消费者和生产者
- **ConsumerDiscoveryService**：自动扫描装饰器，注册消费者
- **双 Provider**：OpenSourceRocketMQProvider / TencentRocketMQProvider
- **工厂模式**：MqClientFactory 根据配置创建 Provider
- **消息接口**：Consumer / Producer / Message 抽象

## 核心论点

### 1. 装饰器驱动的消息处理

- `@Handler(topic, consumerGroup)` 标注消费者方法
- `@Producer(topic)` 标注生产者
- ConsumerDiscoveryService 自动发现并注册

### 2. 双 RocketMQ 实现

- OpenSourceRocketMQProvider — 开源 RocketMQ 5.x
- TencentRocketMQProvider — 腾讯云 RocketMQ

### 3. ProviderRegistry 注册机制

工厂模式 + ProviderRegistry 管理不同 MQ Provider 实例。
